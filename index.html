接线、上传和打开网页

超声波 TRIG = D8（GPIO5），ECHO = D9（GPIO2）。LIS2DH 和 OLED 接 I2C：SDA = GPIO21，SCL = GPIO22。灯带 DIN = D2（GPIO25），灯带要单独供电并和主板共地。

用 Arduino IDE 打开 esp32_water_monitor/esp32_water_monitor.ino，开发板选 FireBeetle-ESP32（或 ESP32 Dev Module），上传。蓝牙名称是 B-Water。

正式网页地址：https://liujibin-keystone.github.io/water-level-monitor/。网页蓝牙只能在电脑的 Chrome 或 Edge，以及安卓手机的 Chrome 里使用。iPhone 上的 Google 浏览器、Edge 和 Safari 都不能连接蓝牙。若必须用 iPhone，请在 App Store 安装 Bluefy，再用它打开上面的网址。本机调试时，双击同目录的「打开水位监测网页.command」，或运行 python3 -m http.server 8765 后打开 http://localhost:8765/水位监测.html。

Mind+ 工程里没有 GPS 模块，定位用的是打开这个网页的电脑或手机。
